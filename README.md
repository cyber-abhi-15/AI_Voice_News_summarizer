# Smart News Reader – AI Voice News Summarizer

## Overview
Smart News Reader is a voice-first AI application that fetches the latest news, summarizes the content using artificial intelligence, and converts the summary into natural speech.

Instead of reading long news articles, users can listen to short voice briefings that provide the key information quickly and efficiently.

This project was built for the Murf AI Voice Hackathon 2026.

---

## Problem Statement
In today's fast-paced world, people often do not have enough time to read long news articles. Important information is usually hidden in lengthy text, making it difficult to quickly understand the key points.

Our solution provides a system that automatically summarizes news articles and converts them into short voice briefings.

---

## Features
- Fetches latest news articles
- AI-based text summarization
- Converts text summaries into natural voice
- Provides quick audio news updates
- Simple and automated workflow

---

## Technologies Used
- Python
- NewsAPI (for retrieving latest news)
- Google Gemini API (for AI summarization)
- Murf AI Text-to-Speech API (for generating voice)
- Google Colab

---

## System Workflow
1. Fetch latest news articles using NewsAPI
2. Extract the article text
3. Generate a short summary using AI
4. Convert the summary into speech using Murf API
5. Play the generated audio news briefing
